PowerKick для Windows 10/11 x64 (MyDarknessDays)

1. Скопируйте папку PowerKick.vst3 целиком в
   C:\Program Files\Common Files\VST3\
2. Перезапустите DAW и обновите список плагинов (Ableton: Options > Preferences > Plug-ins > Rescan;
   FL Studio: Options > Manage plugins > Find plugins).
3. PowerKick.exe — отдельное приложение, работает без DAW.

Сборка сделана на Mac (Clang в режиме MSVC, Windows SDK 10.0.26100) и проверена в Wine:
тесты движка 194/194, плагин загружается и описывает себя. В настоящей Windows и в
Windows-DAW не проверялась. Цифровой подписи нет: Windows может показать предупреждение.
